## Featured Projects

### 1. Car Fault Diagnosis Expert System

[**View Repository →**](https://github.com/SANIKALCHAVAN/Car-Fault-Diagnosis-Expert-System)

A rule-based expert system that uses user-provided symptoms to identify possible vehicle faults and suggest appropriate next steps.

**Highlights**
- Diagnoses common battery, engine overheating, brake, tire, and starting problems.
- Uses facts and logical rules to map symptoms to possible faults.
- Provides recommendations for recognized faults.
- Includes sample inputs, expected outputs, and test cases.

**Technologies:** `Prolog` · `SWI-Prolog`

### 2. AI Search Algorithms

[**View Repository →**](https://github.com/SANIKALCHAVAN/AIML_Search_Algorithms)

An AI practical project demonstrating different search strategies for solving graph-based problems and exploring state spaces.

**Algorithms implemented**
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Best-First Search
- A* Search
- Hill Climbing
- N-Queens using backtracking

**What it demonstrates**
- Graph representation and pathfinding
- Heuristic-based search
- Path-cost reasoning
- Backtracking for constraint-based problems

**Technologies:** `Prolog` · `SWI-Prolog`

### 3. Vacuum Cleaner Intelligent Agent

[**View Repository →**](https://github.com/SANIKALCHAVAN/AIML-Practical-1-Vacuum-Cleaner-Agent)

A simple intelligent-agent implementation demonstrating the PEAS framework (Performance Measure, Environment, Actuators, and Sensors).

The agent evaluates room conditions, cleans dirty rooms, moves between connected locations, and stops when the environment is clean.

**Concepts explored**
- PEAS task-environment description
- Rule-based decision-making
- Environment states and actions
- Intelligent-agent behavior

**Technologies:** `Prolog` · `SWISH`
